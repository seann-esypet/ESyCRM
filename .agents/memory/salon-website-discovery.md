---
name: Salon website discovery
description: Distinguishing business-listing website fields from organic web discovery and live-site verification
---

When a Maps listing has no website, a general web search can still find a directory-listed domain or matching social profile. A discovered URL is a lead, not proof that a working official website exists or that it publishes an email.

**Why:** The user independently confirmed general web search found a website address missed by the Maps-only pilot. In the checked case the listed domain did not serve a public site, demonstrating that discovery and verification are distinct outcomes.

**How to apply:** For future email-first rules, consider a bounded organic-search step after Maps lacks a site. Cross-check candidate domains and social profiles against salon name, address, and phone; reject inaccessible or unrelated destinations, and only credit an email visible on a verified salon-associated page.
