The 20 requests recorded in the existing pilot evidence copy had **already exhausted this experiment's 20-call cap** when this review started. They are not 20 additional requests made for this report. The live application usage check on September 28, 2026 showed **53/200 monthly hard-stop credits** and **0/20 calls in the preceding hour**; no new SerpApi request was made during this review. The source pilot tab records one public-web and one Facebook search per row with individual queries, selected result links, matching clues, statuses, and call counts. The reviewed copy adds Place IDs, available phone clues, inspectable query links, and an **Organic query results** tab listing each cached provider result (including empty responses) with its source URL and indexed snippet. These are search results, not directly verified salon pages.

**Review-only, carried forward:** Doggy Style Salon's `simpforpaws@gmail.com` appears in an older indexed Facebook result that matched 1511 Firestone Blvd and phone, but the Facebook page was blocked (403). Towne House's `info@townehousegrooming.com` appeared on a matching Nextdoor listing; accessible salon pages did not directly display that email. Neither address was counted as newly verified or written into the main sheet. The matching Best Paws Facebook post showed address and phone, but no email. Other source matches were directories, no-email salon pages, or unrelated search hits; emails from similarly named businesses, Facebook groups, and other locations were rejected. No vendor-support or purpose-restricted mailbox qualifies as a salon general contact.

**Outcome:** Incremental verified yield **0/10**; total verified yield remains **5/20** from the baseline, with **51 combined provider calls across both passes** (31 + 20). There were no imports, sequence enrollments, or messages. The new workbook is `salon-directory-with-public-web-facebook-reviewed.xlsx`. Its four original sheets have identical cell values to the second-pilot source (including all main email cells); only the separate pilot evidence tab has been added/expanded. Search results and blocked social pages are evidence for review, not direct confirmation of a live public salon email.
