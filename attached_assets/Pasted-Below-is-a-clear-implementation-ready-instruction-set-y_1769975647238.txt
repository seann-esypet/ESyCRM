## Goal

Add a **Lead Discovery & Qualification Module** to the existing CRM Replit app that:

1. Searches the internet for **pet grooming businesses by ZIP code**
2. **Deduplicates** results
3. **Extracts contact + website + booking software data**
4. **Qualifies** each business as:

   * Uses grooming software → **Yes**
   * Does not use grooming software → **No**
   * Unable to determine → **Unknown**
5. **Outputs results** either:

   * Directly into the CRM database **OR**
   * As a **CSV/Excel file** formatted for CRM import

## Step-by-Step Logic (MANDATORY ORDER)

---

### STEP 1: ZIP-BASED SEARCH GENERATION

For each ZIP code, generate **all** search queries below:

```
"Grooming shop in [STATE], Zip code [ZIP]"
"Grooming salon in [STATE], Zip code [ZIP]"
"Pet Grooming shop in [STATE], Zip code [ZIP]"
"Pet Grooming salon in [STATE], Zip code [ZIP]"
"Dog Groomer in [STATE], Zip code [ZIP]"
"Dog Grooming shop in [STATE], Zip code [ZIP]"
"Cat Grooming shop in [STATE], Zip code [ZIP]"
"Dog Grooming salon in [STATE], Zip code [ZIP]"
```

Each query should record:

* `queryString`
* `searchEngine`
* `zipCode`
* `state`

---

### STEP 2: SEARCH EXECUTION

For each query:

* Use **search result scraping APIs** or SERP providers (NOT raw browser scraping)
* Extract:

  * Business name
  * Business website (if shown)
  * Google Business Profile URL (if available)
  * Phone number
  * Email (if visible)
  * Address / ZIP confirmation

Store raw results temporarily.

---

### STEP 3: DEDUPLICATION LOGIC

A business is considered a duplicate if **ANY** match:

* Same website domain
* Same phone number
* Same business name + ZIP

Deduplication must happen **before** website crawling.

---

### STEP 4: WEBSITE DETECTION

For each unique business:

#### Determine Column K — Has Web Site

* If website URL exists → `Yes`
* If explicitly no site found → `No`
* If unclear → `Unknown`

#### Column L — Web Site Address

* Store homepage URL only
* Normalize (remove tracking params)

---

### STEP 5: WEBSITE CRAWLING & BOOKING BUTTON DETECTION

If website exists:

1. Crawl homepage + Contact + About pages
2. Look for **buttons or links** containing:

   ```
   Book
   Book Now
   Book Here
   Schedule
   Appointment
   Groom
   Grooming
   ```
3. Extract **destination URL** (redirect target)

---

### STEP 6: SOFTWARE IDENTIFICATION (CRITICAL LOGIC)

Analyze booking URL domain or path.

Use **pattern matching**, examples:

| URL Pattern          | Software         |
| -------------------- | ---------------- |
| booking.moego.pet    | MoeGo            |
| petgroomerfinder.com | PetGroomerFinder |
| pocketsuite.io       | PocketSuite      |
| pawtastic.app        | Pawtastic        |
| runloyal.com         | RunLoyal         |
| vagaro.com           | Vagaro           |

Logic:

* If known booking platform detected:

  * Column H → `Yes`
  * Column I → Software name
  * Column J → Booking URL
* If booking exists but software unknown:

  * Column H → `Yes`
  * Column I → `Unknown`
* If no booking system found:

  * Column H → `No`

---

### STEP 7: CONTACT DATA EXTRACTION

Attempt in this order:

1. Website Contact page
2. Website footer
3. About / About Us page
4. Google Business Profile

Extract:

* Business Email → Column D
* Business Phone → Column E
* Business Name → Column F

---

### STEP 8: OWNER / PERSON IDENTIFICATION

Attempt to locate:

* Owner name
* Founder
* Groomer lead

Sources:

* About page
* Team page
* Social media links

If found:

* Split into:

  * Column B → firstName
  * Column C → lastName
  * Column G → jobTitle

If not found:

* Leave blank (do NOT guess)

---

### STEP 9: CONTACT FORM DETECTION

If website exists:

* Look for forms with:

  ```
  /contact
  /contact-us
  /get-in-touch
  ```
* Store form URL in Column M

---

### STEP 10: METADATA FIELDS

* Column N — source
  Example:

  ```
  Google Search
  Bing Search
  Business Directory
  Social Media
  ```

* Column O — notes
  Examples:

  ```
  Booking link detected but software unclear
  No website found, Google profile only
  ```

* Column P — userID
  Assign logged-in CRM user ID
