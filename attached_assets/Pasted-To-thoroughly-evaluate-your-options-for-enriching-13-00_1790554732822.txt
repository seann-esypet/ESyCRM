Part 2: Technical Constraints & Platform Analysis
1. Context Discrimination (Salon vs. Provider & Booking vs. Inquiry)
No tool natively filters out third-party provider emails or booking forms out of the box.
• The Problem: Broad email crawlers will pull support@squarespace.com, info@vagaro.com, or hello@boulevard.com if they are embedded in the footer or widget code of the salon's website. Similarly, any URL containing a form or booking element may be misclassified as a "general contact form."
• The Solution: To achieve accurate results, you must implement post-processing scripts or keyword filters (e.g., stripping out known booking domains like Vagaro, Mindbody, Boulevard, Phorest, Fresha, Squarespace, Wix, Shopify from the scraped strings).
2. Facebook Page Data & Permissions
• Terms & Login Permissions: Scraping Facebook data using an authenticated user session violates Meta’s Terms of Service and can result in account bans. To avoid this, tools like Apify and Outscraper use unauthenticated ("No-Login") edge-scraping nodes that read public-facing mobile versions or public endpoints of Facebook Pages. [1] (https://apify.com/get-leads/all-in-one-facebook-scraper), [2] (https://apify.com/alfalfa/facebook-pages-scraper)
• Email Availability: Public emails listed in a Facebook Page's "About" section are retrievable through these scraping configurations. However, access can be spotty because Meta frequently updates its scraping counter-measures, which can cause temporary connection errors or blank returns. [1] (https://x.com/moritzkremb/status/2038912642018955753), [2] (https://apify.com/alfalfa/facebook-pages-scraper)
3. Evidence Fields Needed for a Human Review Queue
To audit your data and prevent high bounce rates, your data schema should store the following verification fields:
1. google_place_id: The immutable source anchor.
2. extracted_email: The raw string discovered.
3. email_source_url: The exact subpage (e.g., ://salon.com) where the email was found.
4. email_domain_match: Boolean confirming if the email domain matches the salon's official website domain (helps instantly flag third-party providers like @gmail.com or @bookingprovider.com).
5. contact_form_url: The specific address of the contact page.
6. form_type_guess: A flag indicating if keywords like booking, appointment, or schedule dominate the form's URL path.

Before committing to the full dataset, run a controlled test using a subset of your data to evaluate performance.

Select 240 total listings distributed evenly to ensure a representative sample across different regions and data qualities:
• State Distribution: 80 listings from State A, 80 from State B, and 80 from State C.
• Data Type Distribution: Within each state's batch, select 60 listings that already include a website URL and 20 listings without a website URL (to test each tool's ability to discover missing sites or fall back to Facebook).
